# Type Theory in a Lean Context

**Abstract:**
Type Theory is a foundational system for mathematics in which mathematical objects are represented as Types, which serve as a versatile framework for constructing mathematical objects and proving statements about them. Type Theory has seen recent interest due to its application in Interactive Theorem Provers such as Lean, Coq, Agda, etc.

We will talk about the foundational setting that Type Theory is based in, along with the interpretation of mathematical propositions and their proofs as types and terms respectively via the Curry-Howard Correspondence. We will also talk about the central concept of inductive types, which allow one to express mathematics in type theory.

The talk will be accompanied by hands-on demonstrations using examples in Lean.
